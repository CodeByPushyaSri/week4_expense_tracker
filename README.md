# Expense Tracker – Flutter Application

A Flutter-based Expense Tracker application developed as part of the Week 4 Flutter Internship Final Development Assignment.

The application helps users manage their personal finances by tracking income and expenses, organizing transactions into categories, and viewing spending summaries.

## Features

### 1. Dashboard
- View total balance.
- View total income.
- View total expenses.
- Display recent expenses.
- Quick access to add a new expense.

### 2. Expense Management
- Add new expenses.
- Edit existing expenses.
- Delete expenses.
- View expense details.
- Browse expense history.

### 3. Categories
- Organize expenses by category.
- View expenses based on their categories.
- Identify different types of spending.

### 4. Monthly Summary
- View monthly spending information.
- Monitor income and expenses.
- Understand overall spending patterns.

### 5. Profile
- Access the user profile section.
- View profile-related information.

### 6. Settings
- Access application settings.

### 7. User Interface
- Material Design interface.
- Purple-themed design.
- Bottom navigation for easy access to different sections.
- Responsive layout for different screen sizes.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following:

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Flutter and Dart extensions

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/CodeByPushyaSri/week4_expense_tracker.git
```

**2. Open the project folder**

```bash
cd week4_expense_tracker
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

To run the application in Google Chrome:

```bash
flutter run -d chrome
```
